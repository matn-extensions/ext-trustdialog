# Workspace Trust Shield

Security prompt preventing automatic code execution in untrusted directories

## Details
- **Identifier**: `matn.ext.trustdialog`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Workspace Trust Shield**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-trustdialog
```
